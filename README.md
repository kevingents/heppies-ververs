# heppies-ververs

Haalt elk kwartier https://heppies.app/api/nieuws op, zodat Heppies ook op rustige momenten
nieuw goed nieuws verzamelt en pushberichten verstuurt. Bevat niets geheims.

Eén keer per maand maakt de workflow een lege commit, omdat GitHub geplande workflows
in een repo zonder activiteit na 60 dagen uitzet.
